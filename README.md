## English

DefinitelyWorking is a stealth productivity simulator and joke application designed to display ultra-complex, high-tech-looking screens on your monitor. 

It gives the illusion that you are engaged in deep, critical engineering work when you need to make your screen look "extremely busy" at the office or during remote work sessions.

🌐 **For detailed specifications and support, please visit the [Official Website](https://chililikobo.github.io/en/).**

### 🚀 Installation (Portable)

No installation or special configuration is required. Simply place the downloaded folder (containing `DefinitelyWorking.exe` and its accompanying DLL file) in your preferred location and run the executable. To uninstall, just delete the folder.

**Portable Design:** This software is designed to be fully portable. Compiled with Native AOT technology, it launches instantly without footprint or dependency overhead, and does not require any additional .NET Runtime.

* **Supported OS**: Windows 10 / Windows 11 (64-bit)
* **Supported OS (Server)**: Windows Server 2016 / 2019 / 2022 / 2025

### 🛠 Key Features & Usage

#### 1. 5 Switchable "Working Hard" Themes
Instantly toggle between 5 high-tech theme presets using F1–F5 hotkeys:
- **F1**: SysAdmin / Cyberpunk Hacker (Matrix code rain & live attack logs)
- **F2**: AI Research / AGI LLM Cluster (Epoch, loss function, GPU temp)
- **F3**: Stonks / Wall Street Quant (Diamond Hands trading engine & live tickers)
- **F4**: DevOps / Server Infrastructure Monitor (CPU, memory leaks, tech debt)
- **F5**: Quantum Sync / Subspace Analyzer (Schrödinger's bug debugging)

#### 2. Dynamic Humor Log Generation
Displays hilarious real-time updating progress bars, terminal output, and status metrics packed with programmer and office worker memes.

#### 3. Stealth UI Switching
In addition to key bindings, a semi-transparent stealth dropdown appears in the bottom-right corner when hovered over with the mouse for discreet theme switching.

#### 4. Ultra-Fast Portable Operation
Compiled natively, ensuring fast startup and minimal resource consumption.

## 日本語

DefinitelyWorkingは、PC画面上に「高度で複雑な作業を行っている風」のダミー画面を表示し、周囲や上司に対してあたかも超高度な業務を進行中であるかのように見せかけるステルスプログラミング＆ワークシミュレーター（ジョークツール）です。

オフィスワークやリモートワーク中に画面を「超多忙モード」へ一瞬で偽装し、プログラマーやエンジニアあるあるネタ満載の動的アニメーション画面を提供します。

🌐 **詳細な仕様やサポート情報については、[公式ホームページ](https://chililikobo.github.io/) をご覧ください。**

### 🚀 インストール (ポータブル対応)

インストール作業や特別な設定は不要です。ダウンロードした `DefinitelyWorking.exe` および付属のDLLが含まれるフォルダを任意の場所に配置し、実行ファイルをダブルクリックするだけで使用できます。アンインストールはフォルダごと削除するだけです。

**ポータブル設計:** 本ソフトウェアはNative AOT形式でコンパイルされており、ポータブルに設計されています。.NETランタイム等の追加インストールは一切不要で、環境を汚さずどのPCでも即座に起動して利用できます。

* **対応OS**: Windows 10 / Windows 11 (64-bit)
* **対応OS (サーバー)**: Windows Server 2016 / 2019 / 2022 / 2025

### 🛠 主な機能と使い方

#### 1. 5種類の本格的な「偽装作業」テーマ切り替え
F1〜F5キーを押すだけで、以下の高度なプロフェッショナル風画面に一瞬で切り替えが可能です。
- **F1**: SysAdmin / サイバーパンクハッカー（マトリックスレイン＆ログ）
- **F2**: AI Research / AGI LLM学習クラスタ（エポック＆損失関数モニター）
- **F3**: Stonks / 超高速株取引・Quant（ダイヤモンドハンズ・リアルタイムチャート）
- **F4**: DevOps / サーバー監視パネル（CPU負荷・メモリリーク・技術的負債）
- **F5**: Quantum Sync / 量子サブスペースコア（シュレーディンガーのバグ解析）

#### 2. リアルタイム・ジョークログ自動生成
「RAMのダウンロード中」「上司のコーヒーメーカー暗号化」「技術的負債の増大」など、エンジニア・オフィスワーカー向けのユーモアあふれるログやプログレスバーがリアルタイムに変動します。

#### 3. ステルスUI切替機能
キーボードショートカットに加え、画面右下にマウスをホバーさせた時のみうっすら出現するステルス型ドロップダウンメニューからもテーマ切り替えが可能です。

#### 4. 超高速・ポータブル動作
Native AOT技術により起動が非常に高速で、リソース消費も最小限に抑えられています。
